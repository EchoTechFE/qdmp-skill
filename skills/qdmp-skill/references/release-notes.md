# QDMP Skill v1.1.16

Codex、Claude Code 和 Qoder 的插件包版本为 1.1.18。

## 用户可见更新

- Go / Node.js 22 后端支持用 CLI 打包发布、按需审查差异并核对上线结果。部署预检可按权限补齐 AppSecret 和托管 MongoDB 配置，减少手动查找和复制。
- 新建项目使用标准 EMP 全栈模板。旧项目可先预检，再迁移前端目录和公开配置，保留既有后端源码与语言。纯前端任务跳过后端和数据库配置。
- 前端支持用 CLI 提审，并可选择审核通过后自动发布。EMP 真机调试二维码携带 AppID，扫码、上传体验版及正式发布各有明确入口。
- EMP 前端新增按需取数、图片懒加载、列表触底加载和接口分页指引，涵盖请求去重、重试、Android 回调兼容及真机验收。
- PRD 新增只读盘点、压缩和归档流程，可按现行需求合并旧稿，保留关键规则、验收项和来源，并核对文档体积变化。

## 完整更新（按开发影响排序）

1. **生产部署与验收**。按前端、后端或全栈区分预检和授权范围。后端从私有归档构建发布，按需查看脱敏 diff，随后核对 Pipeline、运行版本、副本和健康结果。已有数据库配置可复用。千岛托管 MongoDB 的开通、凭据下发和本地保存按实际状态与授权执行。
2. **标准工程与旧项目迁移**。新建默认使用 EMP 全栈模板。旧项目的 `config migrate --check` 提前显示迁移计划和阻塞，后续迁移拆出 `frontend/`、统一根配置并保留原有后端。旧运行时的源码适配仍需构建和真机验证。
3. **前端提审、发布与真机调试**。CLI 新增提审及审核通过后自动发布选项。真机二维码关联实际 AppID，可结合构建产物、设备日志和体验版本排查问题。
4. **EMP 交互与 API 性能指引**。指导页面和图片按需加载、列表首屏取一页、触底加载及接口分页。补充请求去重、重试、Android 宿主回调兼容和端到端验收，以及 Go、Node.js、Python 业务 API 的性能与兼容规则。
5. **PRD 盘点、压缩和归档**。新增只读盘点脚本，按确认的现行需求去重并合并历史稿，保留规则、验收项和来源。单独整理或审查 PRD 可直接进入文档流程。
6. **工具更新与安装维护**。业务命令前检查并更新受支持的 CLI。Skill 可显示可更新、待重载和首次加载状态。已实际加载并校验正式新版后，清理可验证的重复安装入口。
7. **可选收集的状态与复验**。按实际宿主和项目目录检查收集状态，补充 Hook 审查、已有授权恢复、运行时修复和已授权任务节点记录。

## 升级方式

从原安装渠道更新完整插件或 Skill 目录，然后重新加载宿主或开启新会话。
