# QDMP Skill v1.1.20

## 用户可见更新

- 说「部署」或「发布」即可进入生产部署预检。Skill 按项目情况区分纯前端、仅后端和全栈，核对目标 AppID、登录态和应用权限。
- 搭配 CLI 0.1.37，后端部署可自动补齐缺少的 AppSecret。选择千岛托管 MongoDB 时，可按授权开通实例、等待就绪、下发并保存连接配置。已有配置继续复用。
- 部署预检会检查私有配置的文件权限和 Git 暂存状态。切换登录账号会暂停待执行的写操作。
- 后端发布后可用 CLI 查询 Pipeline、rollout 和运行版本。明确失败、尚待验收及版本不一致会有对应提示。
- 收集引导脚本下载遇到短时网络故障会有限重试。失败后可查看脱敏诊断，并继续使用已确认的工作区授权。

## 发布检查

PR 检查四个 Skill、三端插件、主 Skill 的会话版本和发布说明标题。推送发布标签后再核对实际 Git tag，通过后才创建正式 Release。

## 升级方式

从原安装渠道更新完整插件或 Skill 目录，然后重新加载宿主或开启新会话。收集工具沿用已授权的工作区范围。
