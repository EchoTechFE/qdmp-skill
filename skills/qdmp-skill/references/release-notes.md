# QDMP Skill v1.1.19

## 用户可见更新

- 独立 Skill 和 Codex、Claude Code、Qoder 市场插件统一使用 1.1.19，便于核对宿主显示的安装版本和对话中加载的版本。
- 收集工具仍使用公开版 0.2.18。分发清单同步了 GitHub 当前公开的压缩包、引导脚本、校验值和配套告知，已验证能在干净的 Codex 环境直接下载和安装。

## 发布检查

PR 检查四个 Skill、三端插件、主 Skill 的会话版本和发布说明标题。推送发布标签后再核对实际 Git tag，通过后才创建正式 Release。

## 升级方式

从原安装渠道更新完整插件或 Skill 目录，然后重新加载宿主或开启新会话。收集工具沿用已授权的工作区范围。
