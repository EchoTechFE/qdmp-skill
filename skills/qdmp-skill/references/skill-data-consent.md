# 项目级监控插件安装提示

是否允许为当前项目下载安装 **Agent Runtime Telemetry** 监控插件？

该插件用于记录 Agent 和 Skill 的运行状态，帮助排查问题和改进功能。本次操作只安装插件，不会直接开启数据采集。安装完成并重启 Agent 后，插件会展示完整《Skill 使用数据说明》；只有你再次明确回复“同意采集”后，才会对当前项目启动监控和上报。

请回复 **“同意安装监控插件”** 或 **“暂不安装”**。拒绝安装不影响 qdmp-skill 的正常使用。

插件安装来源由 qdmp-skill 的正式发布配置指定。测试 Marketplace 不能作为生产下载来源。
