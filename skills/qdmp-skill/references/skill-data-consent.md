## Agent 授权询问文案

是否允许我们收集你在当前项目中使用 Agent 和 Skill 期间产生的运行信息，用于问题排查和功能改进？

本次授权以系统识别出的当前项目为范围，其他项目需另行授权。收集内容包括用户与会话标识、Agent 和模型信息、任务输入、Skill 使用记录、工具调用参数及结果、文件改动记录、耗时和错误信息。其中可能包含代码或文件内容，并会上传至我们的服务端。

请回复 **“同意采集”** 或 **“不同意”**。未明确同意前不会开始采集，拒绝不影响 Skill 正常使用。

## 使用数据说明

为排查运行问题、评估 Skill 使用效果并改进功能，千岛开放平台将在获得你的同意后，收集和使用以下信息。

### 收集哪些信息

- 用户、项目和会话标识，用于关联同一次任务的运行记录。
- Agent、宿主、模型及可获取的版本信息，用于分析不同运行环境的表现。
- 任务输入、Skill 使用记录、工具调用参数及结果、耗时和错误信息，用于还原执行过程、定位问题。
- 文件改动记录及相关产物信息。任务输入和工具调用记录中可能包含代码、文件内容或其他由你提供的信息。

当前项目由系统识别为 QDMP 项目根目录、Git 仓库根目录，或启用采集时注册的文件夹。归属于该项目根目录及其子目录的会话才会被采集，自动文件改动扫描也仅覆盖这一范围，不主动扫描其他项目。具体可记录字段取决于所用 Agent 和宿主能够提供的信息；如果你在当前项目会话中要求 Agent 访问项目外内容，相关工具调用参数和结果仍可能进入运行记录。

### 信息如何使用和保存

上述信息将上传至由回响科技运营、部署在中华人民共和国境内的服务端，用于问题排查、使用情况统计和 Skill 效果评测，仅由履行上述职责所需的授权人员访问。

数据保存期限为 1 年，到期后将匿名化处理。如需用于本说明之外的其他用途，我们会另行告知并取得相应授权。

### 你可以如何选择

数据采集为可选项。只有在你明确回复“同意采集”后才会开启；拒绝授权不影响 Skill 的正常功能。

授权以当前项目为范围保存，并适用于该项目后续的 Agent 会话。你可以随时在当前项目的 Agent 对话中发送“关闭数据采集”停止后续采集；发送“开启数据采集”可重新授权，发送“查看数据采集状态”可查看当前授权状态。关闭后不再收集新的运行信息。如需查询或申请删除已收集的数据，可以发送“删除已收集的数据”或联系 `openqiandao@echo.tech`。

### 信息保护

我们会采取访问控制、传输与存储保护等措施，并对部分常见密钥和凭证进行过滤。但自动过滤无法识别所有敏感内容，请避免在任务输入、代码或工具输出中包含密码、访问令牌及其他不宜提供的信息。

如对本说明有疑问，请联系 `openqiandao@echo.tech`。
