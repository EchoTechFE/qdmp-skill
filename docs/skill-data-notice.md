# Skill 数据采集授权文案

草案：以下包含 Agent 对话中的授权询问文案和《Skill 使用数据说明》。上线前需补齐方括号内信息，由研发核对实际功能并交法务确认；“未同意不采集”“拒绝不影响使用”等表述须与实际实现一致。

## 1. Agent 授权询问文案

安装入口的“拒绝选择结果”与本插件的运行监控分开：仅在选择前展示 `monitor-install-decision-v1` 说明、用户明确拒绝安装且未要求不发送选择结果时，由本项目发布的独立 onboarding 工具直接发送最小化拒绝事件；不安装监控插件、不登录、不启动 Collector。用户选择前必须知道事件字段、正式接口与网络来源 IP 可见性，并提供“暂不开启，也不要上报选择结果”选项。无提前告知的历史拒绝不补报。完整提示见本项目 [一次授权说明](onboarding-consent.md)，字段白名单由本项目的 `scripts/monitor-decision.mjs` 维护；QDMP Skill 只提供指引。拒绝事件不包含项目/账号/设备/会话标识、路径或对话内容。发布前仍须按本文草案要求核对用途与告知内容。

QDMP 一次授权入口使用协议标识 `install-monitor-production-v1`：在显示当前绝对项目根目录及本说明后，明确询问是否同意“安装插件、持续监控当前工作目录、正式上报”，确认语为“同意安装并开启监控和正式上报”。**当前版本上传至正式采集接口 `https://c.qiandao.cn/collect`，包括监控日志、撤回事件和安装拒绝结果；内置 dev 地址配置归一到正式接口，生产登录不变。**接口接收成功不等于已落库，需独立查询验证。该明确确认等价于本说明的采集同意，并额外记录三项权限；旧版仅安装同意不能迁移。授权适用于重启后恢复同一任务以及不再触发 Skill 的普通对话，不回溯采集授权前历史。宿主仍可能要求用户审查信任 Hook，未加载或信任期间不承诺采集。下述“同意采集”入口保留兼容已有单独采集流程，其他自定义采集接口不变。

已安装兼容插件时，新独立目录使用 `monitor-production-v1`，确认“使用已安装版本，仅同意当前目录监控和正式上报”，不再授予插件安装或更新权限。用户希望同时更新并开启新目录时使用 `update-monitor-production-v1`，明确展示当前与目标版本，确认“同意更新并开启当前目录监控和正式上报”。这两种确认均包含下述当前项目的数据说明及正式上报范围；后台维护限于已安装运行时。仅更新插件不代表新目录采集同意，也不改变已有项目授权。拒绝更新不发送安装拒绝事件。

是否允许我们收集你在当前项目中使用 Agent 和 Skill 期间产生的运行信息，用于问题排查和功能改进？

本次授权以系统识别出的当前项目为范围，其他项目需另行授权。收集内容包括用户与会话标识、Agent 和模型信息、任务输入、Skill 使用记录、工具调用参数及结果、文件改动记录、耗时和错误信息。其中可能包含代码或文件内容，并会上传至我们的服务端。

请回复 **“同意采集”** 或 **“不同意”**。同意后会先检查千岛登录状态；未登录时将展示千岛现有的扫码或浏览器登录入口，登录完成后才会开启当前项目的数据采集。监控组件不会读取、复制或上传登录 Token。未明确同意或未完成登录前不会开始采集，拒绝不影响 Skill 正常使用。

## 2. 使用数据说明

为排查运行问题、评估 Skill 使用效果并改进功能，千岛开放平台将在获得你的同意后，收集和使用以下信息。

### 收集哪些信息

- 匿名安装、项目和会话标识，以及授权时的千岛登录验证状态，用于关联同一次任务的运行记录。当前版本不采集千岛账号 ID、昵称或登录 Token。
- Agent、宿主、模型及可获取的版本信息，用于分析不同运行环境的表现。
- 任务输入、Skill 使用记录、工具调用参数及结果、耗时和错误信息，用于还原执行过程、定位问题。
- 文件改动记录及相关产物信息。任务输入和工具调用记录中可能包含代码、文件内容或其他由你提供的信息。

当前项目由系统识别为 QDMP 项目根目录、Git 仓库根目录，或启用采集时注册的文件夹。归属于该项目根目录及其子目录的会话才会被采集，自动文件改动扫描也仅覆盖这一范围，不主动扫描其他项目。具体可记录字段取决于所用 Agent 和宿主能够提供的信息；如果你在当前项目会话中要求 Agent 访问项目外内容，相关工具调用参数和结果仍可能进入运行记录。

### 信息如何使用和保存

上述信息将上传至由回响科技运营、部署在中华人民共和国境内的服务端，用于问题排查、使用情况统计和 Skill 效果评测，仅由履行上述职责所需的授权人员访问。

数据保存期限为 1 年，到期后将匿名化处理。如需用于本说明之外的其他用途，我们会另行告知并取得相应授权。

### 你可以如何选择

数据采集为可选项。只有在你明确回复“同意采集”，或在 QDMP 一次授权入口明确回复“同意安装并开启监控和正式上报”后才会开启；拒绝授权不影响 Skill 的正常功能。

授权以当前项目为范围保存，并适用于该项目后续的 Agent 会话。你可以随时在当前项目的 Agent 对话中发送“关闭数据采集”停止后续采集；发送“开启数据采集”可重新授权，发送“查看数据采集状态”可查看当前授权状态。关闭后不再收集新的运行信息。如需查询或申请删除已收集的数据，可以发送“删除已收集的数据”或联系 `openqiandao@echo.tech`。

### 信息保护

我们会采取访问控制、传输与存储保护等措施，并对部分常见密钥和凭证进行过滤。但自动过滤无法识别所有敏感内容，请避免在任务输入、代码或工具输出中包含密码、访问令牌及其他不宜提供的信息。

如对本说明有疑问，请联系 `openqiandao@echo.tech`。
